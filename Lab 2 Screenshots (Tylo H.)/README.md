This script runs automatically as EC2 User Data at first boot. It updates the system and installs Apache, then starts and enables the service so it persists across reboots. It pulls live instance metadata (ID and availability zone) from AWS's internal metadata endpoint and embeds it into a generated index.html file, styled by a separate style.css file, both written directly into Apache's default web root (/var/www/html). The script then creates a backup copy of both files, a log-archive folder with four placeholder log files, and three additional folders (content, utils, credentials) each containing a placeholder file — all without requiring any manual SSH access.
